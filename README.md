SmartWaste

A Smarter Way to Recycle

SmartWaste is a web-based recycling platform designed to make recycling more convenient, accessible, and rewarding.

The platform connects users with recycling services and centres, allowing them to manage recyclable waste, request collections, discover nearby recycling locations, and track their recycling activity in one place.

---

The Problem

Although recycling facilities and collection services are available, recycling can still be inconvenient for many people.

Common challenges include:

* Difficulty finding suitable recycling centres
* Lack of convenient recycling collection options
* Uncertainty about how to properly manage recyclable materials
* Limited motivation to recycle consistently
* Lack of visibility into individual recycling contributions

These barriers can cause recyclable materials to end up in general waste.

---

Our Solution

SmartWaste brings different parts of the recycling process together into one platform.

Users can:

* Find nearby recycling centres using an interactive map
* Request recyclable waste collection
* Record and manage their recyclable materials
* Track their recycling activity
* Earn rewards for participating in recycling
* Monitor their environmental contribution

Our goal is to make recycling **simple, convenient, and rewarding.

---

Key Features

Recycling Centre Map

Users can explore nearby recycling centres through an interactive map and find suitable recycling locations.

Waste Collection

Users can submit collection requests for their recyclable waste without needing to personally transport larger amounts of recyclables.

Recycling Tracking

Users can keep track of their recycling activity and see their contributions over time.

Rewards

A reward system encourages users to participate in recycling consistently and turns sustainable actions into meaningful incentives.

User Dashboard

Users can access their recycling information, collection activity, and rewards from one central dashboard.

How It Works

1. User registers
        ↓
2. Selects recyclable materials
        ↓
3. Finds a recycling centre
   or requests a collection
        ↓
4. Recyclables are collected
   and sent for recycling
        ↓
5. User records their contribution
        ↓
6. User earns rewards

---

What Makes SmartWaste Different?

SmartWaste does more than provide information about recycling centres.

It focuses on the complete user experience by bringing **discovery, collection, tracking, and rewards** together in one platform.

Instead of asking users to navigate multiple services, SmartWaste aims to reduce the barriers between wanting to recycle and actually doing it.

Resident → Collection → Recycling → Rewards

Getting Started

### Prerequisites

Before running SmartWaste locally, make sure you have:

* XAMPP
* PHP
* MySQL
* A modern web browser

Installation

1. Clone this repository:

```bash
git clone https://github.com/your-username/smartwaste.git
```

2. Move the project into your XAMPP `htdocs` directory.

3. Start Apache and MySQL through XAMPP.

4. Create the SmartWaste database using the provided SQL file.

5. Configure the database connection according to your local environment.

6. Open the project in your browser:
http://localhost/smartwaste
